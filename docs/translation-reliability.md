# Надстрочный перевод и ежедневное чтение

Перевод остаётся над исходными словами. «Знаю» скрывает подсказку, «Изучаю» сохраняет доступную подсказку и пунктирное подчёркивание. Уровень CEFR по-прежнему задаёт общую видимость остальных переводов.

## Что изменилось

- Сначала обрабатывается текущая страница; сохранённые подсказки появляются из кеша. Небольшая область впереди готовится после неё. Прокрутка объединяет запросы, перелистывание больше не ждёт двухсекундную паузу.
- Azure/Microsoft, Google Cloud и DeepL получают настоящие пакетные запросы. AI сохраняет общий лимитер; перевод имеет приоритет перед фоновым уточнением уровней.
- Неполный ответ сохраняет удачные слова и оставляет пропуски для ограниченного повтора. Пустой ответ или ошибка не становятся успешным переводом. Ответы от отменённой страницы/провайдера не записываются поверх текущих.
- Кеш разделён по языковой паре и провайдеру. Старые неоднозначные записи не используются; словарь и карточки сохраняются. Первое чтение после обновления поэтому может потребовать новых запросов.
- AI обязан явно обозначать слова без подсказки. Проверка покрытия сохраняет исходное написание, пробелы и пунктуацию, а ремонт пропусков получает контекст предложения. Уточнение CEFR обновляет отображение без очистки перевода страницы.
- Ссылки, курсив и выделение фразы сохраняются. Карточка получает исходный текст без надстрочных переводов; переход к примеру использует место в исходной книге.

## Действия со словами и фразами

Нажмите слово: можно изменить перевод карточки, выбрать статус, прослушать произношение выбранным TTS и отдельно запросить AI-пояснение с контекстом. Пояснение использует настроенный AI и не запрашивается автоматически при открытии окна.

Выделите короткую фразу и нажмите **В словарь**. Максимум — 240 символов; более длинный фрагмент не обрезается молча. В **Моём словаре** доступны копирование, системное **Поделиться** и экспорт выбранных изучаемых карточек в Anki. В системном меню можно выбрать Telegram, если он установлен; автоматической отправки нет.

## Быстрая проверка на устройстве

1. Выберите языковую пару и настроенный Azure/Microsoft либо AI. Откройте новую страницу, затем вернитесь на неё: сохранённые подсказки должны появиться без повторного перевода.
2. Быстро перелистните несколько страниц: поздние ответы не должны менять текущую страницу. Проверьте поведение при временном отключении сети и возвращении соединения.
3. Пометьте слово «Знаю», другое — «Изучаю», измените CEFR и перезапустите приложение. Проверьте видимость и сохранение статусов.
4. Сохраните фразу с курсивом, откройте её пример из словаря и попробуйте произношение/пояснение/поделиться. Импортируйте небольшой CSV в Anki по [инструкции словаря](word-learning.md).

Старый неофициальный быстрый Microsoft использовал Edge auth endpoint: публичная проверка 2 октября 2026 получила HTTP 404. Он не восстановлен. Поддержанный Microsoft-путь — Azure Translator с ключом; AI остаётся другим вариантом. Приложение не переключается на AI автоматически при ошибке Microsoft.

## Проверки и пределы

### Исправление Windows после проверки пользователем, 3 октября 2026

Пользователь сообщил о многократных повторах исходного текста. При проверке через настоящий загрузчик книги воспроизведено повреждение исходного текста и подсказок при повторном `readingFeatures`: восстановление сопоставляло тексты по порядковому номеру с уже расширенным ruby DOM. Теперь снимок привязан к исходным текстовым узлам, а применение правил временно отделяет надстрочные элементы. Неизменившийся текст не вызывает повторный перевод; реальные преобразования письма пересоздают подсказки с новым ключом кеша. Также исправлено повторное включение сохранённых подсказок после режима OFF.

Новый `assets/foliate-js/reader-translation-smoke.html` выполняет 29 проверок через настоящий Reader в двух вариантах: исходные модули и production bundle (`?bundle=1`). Покрыты десять обновлений правил/CEFR, выключение/включение режима, сохранение исходной строки, преобразование китайского письма и возврат к оригиналу. Все проверки прошли, прежние 36 браузерных проверок и Node-тест также прошли. Независимое ревью не выявило существенных замечаний; Windows debug пересобран, SHA256 исходных и упакованных скриптов совпадает.

Для проверки новой сборки закройте старое приложение, распакуйте новый ZIP в отдельную папку и снова откройте книгу: это создаёт страницу заново. Локальные карточки и кеш не нужно удалять. Дополнительная проверка на пользовательской книге описана ниже.

Автоматические проверки используют временные данные и подставные ответы провайдеров: покрытие/ремонт слов, пакетный порядок, HTTP 429, отмена, ограничения параллельности, кеш, CSV, восстановление базы и произношение без продолжения главы. Браузерная проверка покрывает оригинальный DOM, выделение, CFI и локальное обновление CEFR.

Реальные задержки и квоты провайдера, TTS/поделиться на физическом устройстве, импорт через интерфейс Anki и синхронизация между двумя устройствами требуют ручной проверки. Для словаря на обоих устройствах нужна совместимая версия схемы базы. Автоматический Telegram, собственный SRS, офлайн-словари и объединение всех словоформ остаются возможными следующими этапами после ежедневного использования.

### Повторные неудачные ответы переводчика, 3 октября 2026

Предыдущее исправление восстановления исходных узлов не покрывало отдельный путь: неполный ответ без маркеров обходил очистку надстрочного слоя. Следующая попытка добавляла ещё одну копию исходной строки, а обновление CEFR могло показывать исходное предложение как перевод. Все ответы теперь проходят общий путь замены слоя; очищаются все его непосредственные старые копии. Ответ без словарных подсказок в режиме уровня CEFR оставляет исходный текст без выдуманного перевода.

На локальной копии пользовательского EPUB, первая глава первого тома, воспроизведены 406 слоёв для 148 исходных элементов и 148 ложных подсказок. После исправления повторные неудачные ответы сохраняют 148 слоёв, без дублей и ложных подсказок. Затем подставной успешный ответ добавляет 1778 надстрочных подсказок, сохраняя все исходные строки. Проверено на исходных модулях и пересобранном production bundle. Текст книги не отправлялся провайдерам и не включён в репозиторий.

Для Azure, Google Cloud и DeepL без API-ключа добавлено явное сообщение о необходимой настройке. Сохранённые переводы продолжают отображаться; отсутствующие не запускают повторные запросы до перелистывания или повторного включения. Провайдер автоматически не меняется. В настройках надстрочного/полнотекстового перевода выберите настроенный AI либо задайте ключ поддерживаемого сервиса, затем снова откройте книгу.

Проверки: 40 браузерных проверок (включая повторные неудачи, CEFR/статусы слов, восстановление успешного ответа и отсутствие ключа), 29 проверок настоящего Reader с production bundle, 20 Flutter-тестов и Node-тест. Анализатор: 76 существующих замечаний, без ошибок и новых замечаний в изменённом коде. Независимое ревью подтвердило восстановление слоя для вложенного форматирования. Windows debug пересобран, хеши исходных и включённых в сборку скриптов совпадают; реальный перевод через API требует настроенного провайдера и отдельно не проверялся.
