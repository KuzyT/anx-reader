# Обновление форка на upstream develop

Основа: `Anxcye/anx-reader` develop, коммит
`2b2df997839ebf3fc6f90f76783b83485d6840d7` (v1.15.0-alpha.25).
Перенесён итоговый функционал старого форка `50f0c385`, без повторного
воспроизведения промежуточных изменений. Flutter — 3.47.2, как в upstream.

Восстановлены:

- надстрочный перевод, режимы чтения и настройки для отдельных книг;
- CEFR A1–C2, цвета подсказок и смена уровня без повторного запроса;
- пакетный AI-перевод, размер пакета и количество работников;
- перевод по словам через обычные сервисы, кеш фрагментов и слов;
- уточнение уровней слов через AI, выбор языка книги;
- статус, история запросов и очистка кеша страницы, главы или книги.

Сохранены новые зависимости, API переводчиков, общий лимитер AI и изменения
ридера из develop. Удалённый upstream старый Microsoft-переводчик не возвращён;
старое значение настройки сопоставляется с Microsoft API.

При интеграции исправлены разбор ответов с блоками рассуждений, выбор полного
перевода для пакетов, применение запоздалых ответов после отмены, гонки
блокировки и подписки при смене провайдера. Создание базы теперь ожидает
завершения миграций. Русские строки восстановленного интерфейса находятся в ARB.
Android compileSdk поднят до 36 по требованиям уже подключённых плагинов;
targetSdk остаётся 35.

## Проверка

- 10 Flutter-тестов: новая база, обновление v7 → v8, открытие старой v8,
  сохранение книг/заметок/позиции/кеша/настроек; JSON и полный перевод;
  отмена пакетов и жизненный цикл настоящего LangChain-потока.
- Node-тест надстрочного режима.
- В браузере 8 проверок реального DOM в iframe: ruby, цвета, CEFR,
  повторный перевод исходного текста, выключение, очистка и поздняя отмена.
- JavaScript-бандл пересобран. Неизменённые PDF-бандлы сохранены из upstream.
- Windows debug и Android debug APK собраны.
- Dart analyzer: ошибок нет; остаются предупреждения и замечания о стиле.

Основные команды из корня проекта (Flutter 3.47.2):

```powershell
flutter pub get --enforce-lockfile
flutter gen-l10n
dart run build_runner build --delete-conflicting-outputs
flutter test
node --test test/interlinear_test.cjs
flutter analyze --no-fatal-infos --no-fatal-warnings
flutter build windows --debug
flutter build apk --debug
```

Для браузерной проверки после `npm ci` в `assets/foliate-js`:

```powershell
node node_modules/http-server/bin/http-server . -a 127.0.0.1 -p 3174 -c-1
```

Открыть `http://127.0.0.1:3174/interlinear-smoke.html`: результат должен содержать
`"passed": true`. Бандл собирается в том же каталоге командой
`node node_modules/webpack-cli/bin/cli.js`.

Проверки используют временные базы и тестовые модели. Пользовательская
библиотека не открывалась. Реальные ответы сетевых переводчиков и поведение на
физическом планшете требуют ручной проверки. «Знаю / изучаю» и экспорт Anki —
следующий этап, они не добавлены в это обновление.
